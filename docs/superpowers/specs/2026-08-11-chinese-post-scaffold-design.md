# Chinese Post Scaffold Design

## Goal

Start a Chinese-language blog post that the site owner will write and edit.

## Scaffold

Create `content/blog/the-odyssey-imax/index.zh.md` as a Hugo page bundle entry with:

- the title `辛苦的一天`;
- the date and last-modified date set to 2026-08-11;
- draft status enabled;
- an empty tag list; and
- `interactionId` set to `the-odyssey-imax`.

Leave the post body empty so the site owner can author it without placeholder text.

## Verification

Confirm that Hugo accepts the new draft and that no unrelated files change.
